# 豚箱計算マクロ（作業予定表(豚) → 計算フォーマット）

「作業予定表印刷(豚)」シートを読んで、計算フォーマット(豚)を自動で作るマクロです。

## ファイル

| ファイル | 中身 | 実行するマクロ名 |
|---|---|---|
| `Module_箱数計算転記_ShiftJIS.bas` | 通常版（印は ●・○ の記号だけ） | `計算フォーマットを作る` |
| `Module_箱数計算転記_色付き_ShiftJIS.bas` | 色付き版（**●数字＝赤**、**○数字＝青** の文字色で出す） | `計算フォーマットを作る_色付き` |

- 判定・計算の中身は2つとも同じです。違いは文字の色だけです。
- どちらか片方を入れれば使えます。両方を同じブックに入れても、マクロ名が違うのでぶつかりません。
- ●＝シートなし（紙の赤丸）、○＝全農でシートあり（紙の青丸）、印なし＝会社でシートあり です。

## ダウンロード

画面右上の緑の［Code］→［Download ZIP］で、まとめてダウンロードできます。

## 入れ替え手順（今お使いの計算フォーマットのブックに入れる）

1. 今お使いの計算フォーマットのブック（.xlsm）を、念のため**別名でコピーしておく**
2. そのブックを開き、`Alt` + `F11` で VBE を開く
3. 左の一覧にある古い `Module_箱数計算転記` を右クリック →［Module_箱数計算転記 の解放］→ エクスポートは［いいえ］
   （色付き版を追加するだけなら、この手順は飛ばしてかまいません）
4. ［ファイル］→［ファイルのインポート］→ 使いたい方の `.bas` を選ぶ
5. ［デバッグ］→［VBAProject のコンパイル］を押し、エラーが出ないことを確かめる
6. 色付き版を使う場合は、ボタン（図形）を右クリック →［マクロの登録］→ `計算フォーマットを作る_色付き` を選ぶ
7. 上書き保存する

箱計算マスタ・略称マスタはそのまま使えます。マスタに新しい表（「■ 1頭セット条件」「■ シートの印」）が無いブックでは、
初回の実行時にマクロが既定の内容で表を自動で追加します。

## 毎日の使い方

1. `作業表加工用マクロ_レイテク作成_2.xlsm` を開き、いつもどおり作業予定表の加工まで済ませる
2. 計算フォーマットのブックも開いたまま、ボタンを押す
3. 「計算フォーマット(豚)」シートに結果が出るので、そのまま印刷する

実行のたびに「計算フォーマット(豚)」と「判定ログ」を作り直します。手で書き足した内容は消えます。

## 注意

- VBE でインポートするときは、必ずこの `_ShiftJIS.bas` を使ってください（日本語が文字化けしないように Shift-JIS で保存しています）。
- インターネットにつながっていない PC でもそのまま動きます。
